# VidTalk

A mobile-first video sharing platform where creators upload their own videos and the community interacts through text comments, short video comments, and threaded video conversations anchored to specific timestamps.

## Development Principles

### 1. End User Experience First
- Fast loading
- Smooth animations
- Responsive UI
- Clear navigation
- Helpful error handling
- Accessible interface

### 2. Meaningful Variables
Use descriptive variable, function, and component names.

Good:
- currentUser
- uploadedVideo
- fetchTrendingVideos()

Bad:
- a
- temp
- data

### 3. No Duplicate Code
Follow the DRY principle.
- Reusable components
- Reusable hooks
- Shared services
- Utility functions

### 4. Correctness
- Validate all inputs
- Handle errors gracefully
- Test features before moving on
- Prioritize reliability over speed

### 5. Best Solution
- Compare approaches before implementation
- Choose maintainable solutions
- Keep code modular
- Avoid unnecessary dependencies

## Mission

Build a complete video sharing platform where video conversations are the primary experience rather than a secondary feature.
